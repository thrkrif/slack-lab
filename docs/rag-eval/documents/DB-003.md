# Read replica lag 증가

Replica lag이 5분을 넘어 조회 API가 오래된 데이터를 반환했다.
The primary had a burst of bulk updates, and the single-threaded replay on the replica could not keep up.
조치: 대량 업데이트를 분산하고, replica 재생 병렬도를 올렸으며, lag이 30초를 넘으면 조회를 primary로 우회하는 플래그를 켠다.
