# CrashLoopBackOff root cause analysis

A pod stuck in CrashLoopBackOff keeps restarting with an exponential back-off delay.
Check `kubectl logs --previous` for the last crash reason, `kubectl describe pod` for OOMKilled or probe failures, and verify the image tag, config maps and secrets mounted into the pod.
