# RabbitMQ 큐 적체와 consumer lag

주문 이벤트 큐가 수만 건 적체되어 알림 발송이 늦어졌다.
Consumer count dropped to one after a deployment because the prefetch setting was missing and a single slow message blocked the channel.
조치: consumer를 4개로 늘리고 prefetch를 10으로 설정했으며 큐 길이 알람을 추가했다.
